# Agent workflow

For implementation, bugfix, code review, and product analysis, publish a compact
Italian report at start, after material plan changes, after each completed
milestone, and at handoff. Use 🟢 completed, 🟡 in progress, ⚪ remaining, and
🔴 blocked. Include overall percentage, measured elapsed time, and estimates;
never present estimates as measurements.

Once authorized, agents continue working autonomously and do not pause merely
to provide status. They pause only for an external blocker, a required user
decision, or a permission boundary; the report names the exact blocker and the
smallest required user action.

Load only `AGENTS.md`, the matching specialist instructions, and the smallest
necessary code, tests, and documentation. For cross-layer or security-sensitive
changes, use a focused review/sub-session when delegation is available. Do not
give two agents ownership of the same file. Distinguish local completion from
deployed completion and update documentation when contracts change.
