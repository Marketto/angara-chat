Use this skill for CR, bugfix, implementation, deployment, and product analysis.

Report in Italian at start, each material plan change, each completed milestone,
and handoff. Use 🟢 completed, 🟡 in progress, ⚪ remaining, 🔴 blocked. Include
overall percentage, measured elapsed time, and estimates for unfinished work.
Never represent estimates as measurements.

Once work is authorized, keep progressing autonomously. Do not stop merely to
report status. Pause only for an external blocker, a required user decision, or
a permission boundary; state the exact blocker and the smallest action needed.

Load only `AGENTS.md`, the relevant `.agents` instruction file, and the smallest
necessary code, tests, and docs. For cross-layer or security-sensitive changes,
request a focused review/sub-session when available; never give two agents the
same file. Clearly distinguish local completion from deployed completion.
